# 재검증 - 진행 전

## 현재 상태
 - Juice Shop의 가격 처리 로직 분석 중, 서버 측 검증 여부와 실제 취약점 존재 여부는 아직 미확인, 따라서 현재는 재검증 단계 미도달

## 재검증을 진행하기 위한 조건
1. 분석 대상 동작을 실습 환경에서 검증
2. 관찰 결과와 증거를 기록
3. 문제가 확인된 경우 대응 방안을 정하고 실제 변경 여부 기록
4. 변경 전후의 동작을 같은 조건에서 비교

## 재검증 시 기록할 내용
- 검증 대상과 수행 조건
- 실행한 요청 또는 사용한 절차
- 변경 전 결과
- 수행한 대응 조치
- 변경 후 결과
- 결과 해석과 검증의 한계

## 진행 상태
- [x] 클라이언트 가격 선택 코드 관찰
- [ ] 서버 측 처리 동작 검증
- [ ] 검증 결과에 따른 대응 조치 결정
- [ ] 대응 후 재검증 수행

## 검증 범위 및 한계
 - 현재까지 확인한 내용은 클라이언트 코드의 가격 선택 흐름. 서버 측 권한 확인, 실제 주문 처리 결과 또는 취약점 악용 성공을 검증한 것 아님.
