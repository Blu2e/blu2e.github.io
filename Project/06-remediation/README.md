# 대응 방안 - 진행 전

## 현재 상태
 - 현재 Juice Shop 실습에서는 상품 가격 처리와 관련된 클라이언트 코드 조사, 서버 측에서 가격과 권한을 어떻게 검증하는지는 미확인

## 현재까지 확인한 내용
- 상품 검색 API 응답에서 `price`와 `deluxePrice` 필드를 확인
- `main.js`에서 Deluxe 여부에 따라 가격 필드를 선택하는 코드를 확인
- 이 사실만으로 서버 측 취약점이 있다고 단정할 수는 없음

## 대응 방안 작성 기준
 - 실제 검증 결과를 얻기 전에는 특정 취약점이 존재하거나 수정되었다고 기록하지 않음

 - 검증 결과 서버 측 검증에 문제가 있는 것으로 확인 시, 확인된 동작과 영향에 맞춰 대응 방안 정리, 문제가 확인되지 않거나 판단이 어려운 경우 그 결과와 한계 기록

## 진행 상태
- [x] 클라이언트 코드에서 가격 선택 로직 확인
- [ ] 서버 측 가격 및 권한 검증 여부 확인
- [ ] 검증 결과에 따른 대응 방안 작성
- [ ] 수정 또는 설정 변경을 실제로 수행한 경우 변경 내역 기록
